# UP Assistant Professor (Higher Education) — General Knowledge 2026
**Exam:** UPESSC, Prayagraj · **Paper:** General Knowledge · **Questions:** 30 · compulsory for all disciplines · 4-option MCQs

The paper has 30 questions spread over 6 units, so each unit contributes only about 4–6 of them. Breadth matters more than depth here. Revise the memory sheets more than once, rather than going deep on any one topic.

Each topic has two files:
- `Questions/` has 10–12 MCQs in the past-paper style. Each question covers a different fact or idea. The answer key and solutions are at the end, and every solution adds one *Also remember* fact.
- `Cheatsheets/` has a **memory sheet** for the same topic: core tables plus **analogies, mnemonics and story hooks**, a "Don't mix up" table and the common exam traps.

See [STYLE-GUIDE.md](STYLE-GUIDE.md) for the question types: `[Fact]`, `[Multi-Statement]`, `[Assertion-Reason]`, `[Match]`, `[Chronology]`, `[NOT-correct]` and `[Application]`.

## Current affairs
Facts in Unit 1 and other time-sensitive facts were checked by web search up to **October 2026**. Each solution states its "as of" date, and the Unit 1 files list the sources checked. Before the exam, add the last 2–3 months of news from a monthly current-affairs digest.
