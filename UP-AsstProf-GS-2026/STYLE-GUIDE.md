# Style Guide — General Knowledge (GS) paper

**Paper:** UPESSC Assistant Professor (Higher Education), General Knowledge. It has 30 questions, is compulsory for all disciplines, and every question is a 4-option MCQ.

## Folder layout
```
Unit-XX-<Name>/
  Questions/NN-<Topic>.md      one file per syllabus sub-topic
  Cheatsheets/NN-<Topic>.md    same filename: a memory sheet built around analogies and mnemonics
```

## Question files
- Each topic has **10–12 questions**, and every one tests a different fact or idea.
- Each question is tagged with its type. Every topic covers every type that makes sense for it:

| Tag | Type | Typical wording |
|---|---|---|
| `[Fact]` | Direct recall | "Who/which/when …" |
| `[Multi-Statement]` | Statements 1, 2, 3, then choose the correct combination | "Which of the statements given above is/are correct?" |
| `[Assertion-Reason]` | A and R, with the 4 standard options | |
| `[Match]` | List-I ↔ List-II, with coded options | "A-2, B-4, C-1, D-3" |
| `[Chronology]` | Arrange events, dates or places in order | "Arrange in chronological order" |
| `[NOT-correct]` | Spot the odd or incorrect one | "Which of the following is NOT correctly matched?" |
| `[Application]` | Scenario, analysis or data question (used mostly for teaching/research aptitude and economy) | "A teacher notices …, the best step is" |

- Difficulty is shown as ★ (easy), ★★ (moderate) or ★★★ (hard).
- The answer key and solutions come at the end. Each solution gives the answer, a one-line reason, and an **extra related fact** that is likely to be asked next.
- For time-sensitive facts (current affairs, rankings, office-holders, figures), the solution says "as of <month year>".

Standard Assertion–Reason options:
(A) Both A and R are true and R is the correct explanation of A
(B) Both A and R are true but R is NOT the correct explanation of A
(C) A is true but R is false
(D) A is false but R is true

## Cheatsheet files (memory sheets)
Each cheatsheet should make the facts **easy to remember**, not just list them. Every sheet has:
1. **Core facts** in compact tables.
2. **Memory hooks**, which are the heart of the sheet:
   - **Analogies.** Compare the concept to something everyday. For example: "The Constitution is the rule-book of a cricket match. Fundamental Rights are the player's rights, enforceable by the umpire (the court). DPSPs are the coach's advice, not enforceable but guiding the game."
   - **Mnemonics and acronyms.** For example, "JLEF" for the Preamble ideals Justice, Liberty, Equality, Fraternity.
   - **Story or visual links** that tie together dates, places and people.
   - **Number tricks** for dates and figures.
3. **Confusable pairs**, set out as a "don't mix up" table.
4. **Exam traps**.
