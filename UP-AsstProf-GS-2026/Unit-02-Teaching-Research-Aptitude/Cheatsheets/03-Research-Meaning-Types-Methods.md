# Memory Sheet · Unit 2 · Topic 03 — Research: Meaning, Types and Methods
> Questions: [../Questions/03-Research-Meaning-Types-Methods.md](../Questions/03-Research-Meaning-Types-Methods.md)

## 1. Core facts

### Meaning
Research is a systematic, objective and replicable search for new knowledge or for solutions to problems. Its key qualities: empirical, logical, cyclical, controlled, critical.

### Types by purpose
| Type | Aim | Who / where | Example |
|---|---|---|---|
| Fundamental (pure/basic) | Build theory, generalise | Researchers, labs | A new theory of learning |
| Applied | Solve a practical problem using theory | Field | Designing a remedial programme |
| Action | Solve an immediate **local** problem | Practitioner (teacher) in own setting | Fixing absenteeism in own college |
| Evaluation | Judge the worth of a programme | Agencies | Impact of a scholarship scheme |

Action research: term coined by **Kurt Lewin** (1940s) and brought into education by **Stephen M. Corey** (1953). It runs as a cycle: Plan → Act → Observe → Reflect.

### Methods
| Method | Time focus | Hallmark |
|---|---|---|
| Historical | Past | Primary/secondary sources. **External** criticism checks genuineness, **internal** criticism checks credibility |
| Descriptive survey | Present | "What is": status, opinions, census-type |
| Experimental | Future ("what will be") | Manipulate the IV, control, randomise |
| Ex post facto (causal-comparative) | Past cause, present effect | IV cannot be manipulated |
| Case study | One unit in depth | Holistic |
| Ethnography | Natural setting | Immersion, participant observation |
| Grounded theory | — | Theory emerges from data (Glaser & Strauss, 1967) |

### Hypothesis and variables
- Null H₀: no difference or relationship. Alternative H₁: there is one.
- **Type I (α)**: rejecting a true H₀. **Type II (β)**: accepting a false H₀. Power = 1 − β.
- Variables: Independent (cause, manipulated) · Dependent (effect, measured) · Extraneous/confounding (unwanted) · Intervening (unobservable link) · Moderator (changes the strength of the IV–DV link).

### Steps of research
Problem → Review of literature → Hypothesis → Research design → Sampling and data collection → Analysis → Interpretation → Report/thesis.

### Ethics and plagiarism (UGC Regulations, 2018)
| Level | Similarity | Status |
|---|---|---|
| 0 | up to 10% | Minor; no penalty |
| 1 | >10%–40% | Penalty |
| 2 | >40%–60% | Heavier penalty |
| 3 | >60% | Severest; for students, registration cancelled |

- Core principles: informed consent, voluntary participation, confidentiality/anonymity, no harm, honest reporting.
- Misconduct: **FFP**, which stands for Fabrication, Falsification, Plagiarism. Self-plagiarism and duplicate publication are also misconduct.

### Thesis writing
- Order: Title page → Certificate/Declaration → Acknowledgement → Abstract → Contents → Chapters (Introduction, Review, Methodology, Results, Discussion/Conclusion) → References → Appendices.
- Research paper format **IMRaD**: Introduction, Methods, Results and Discussion.
- Styles: **APA** (author–date, used in social sciences and education), **MLA** (author–page, used in humanities), Chicago (notes–bibliography).
- References = only the works cited. Bibliography = everything consulted.
- Shodhganga (theses) and Shodhgangotri (synopses) are run by **INFLIBNET, Gandhinagar**.

## 2. Memory hooks
1. **Three researchers, one mango tree.** The *fundamental* researcher asks why mangoes ripen (theory). The *applied* researcher uses that to build a ripening chamber for farmers. The *action* researcher, a Malihabad (Lucknow) orchard owner, tries a fix on his own trees this season.
2. **Historical criticism is like checking a currency note.** *External* criticism asks whether the note is genuine (watermark, date). *Internal* criticism asks whether what is written on it is true (the value claimed). Ex = Exterior = authenticity. In = Inside = content.
3. **Type I = "crying wolf"** (false alarm: rejecting a true null). **Type II = "missing the wolf"** (a real effect left undetected). Court analogy: Type I punishes an innocent person, Type II frees a guilty one.
4. **Time-travel trick for methods**: Historical = **WAS**, Descriptive = **IS**, Experimental = **WILL BE**.
5. **Ex post facto means "after the fact"**: a detective arriving after the crime. He cannot rerun it, only compare clues.
6. **Plagiarism levels "0-10-40-60"**, like a cricket scoreboard. Up to 10 is a "dot ball" (no penalty), and above 60 is "out" (registration cancelled).
7. **FFP = "Fake, Fiddle, Pinch"**: Fabricate (fake data), Falsify (fiddle with data), Plagiarise (pinch words).
8. **Latin pairs**: *Ibid.* = "in the same place" (the immediately previous source). *Op. cit.* = "in the work cited" (earlier, not the immediately previous one). *viz.* = namely. *e.g.* = for example. *i.e.* = that is.
9. **Variables in a recipe**: IV = the amount of sugar you change, DV = the sweetness you taste, extraneous = the fruit's natural sweetness you did not control.
10. **Steps "PRHyDAIR"**, "Pride Air": Problem, Review, Hypothesis, Design/Data, Analysis, Interpretation, Report.

## 3. Don't mix up
| This | Not this |
|---|---|
| Action research term — Kurt Lewin | Action research in education — Stephen Corey |
| External criticism — genuineness | Internal criticism — credibility of content |
| Type I error (α) — reject true H₀ | Type II error (β) — accept false H₀ |
| Ex post facto — no manipulation | Experimental — manipulation of IV |
| Extraneous — outside, uncontrolled | Intervening — internal, unobservable process |
| Internal validity — causation inside the study | External validity — generalisability |
| Ibid. — immediately previous source | Op. cit. — earlier cited work |
| References — only the works cited | Bibliography — everything consulted |
| Shodhganga — full theses | Shodhgangotri — synopses |

## 4. Exam traps
- A smaller α (0.01) means **fewer** Type I errors and **more** Type II errors.
- Action research does **not** aim at wide generalisation. Fundamental research does.
- A hypothesis is a tentative, testable statement. It is not "proved" but rejected or not rejected.
- "Self-plagiarism is allowed because the words are one's own" is **wrong**.
- In scenario questions, the teacher solving a classroom problem in her own institution gives **action research**. A study of a cause that has already occurred gives **ex post facto**.
