# Memory Sheet · Unit 2 · Topic 02 — Evaluation and Factors Affecting Teaching
> Questions: [../Questions/02-Evaluation-Factors-Affecting-Teaching.md](../Questions/02-Evaluation-Factors-Affecting-Teaching.md)

## 1. Core facts

### Types of evaluation
| Type | When | Purpose | Example |
|---|---|---|---|
| Placement | Before instruction | Entry level, grouping | Bridge-course entry test |
| Formative | During instruction | Feedback, improvement ("for learning") | Weekly quiz, assignment |
| Diagnostic | When problems persist | Find causes of difficulty; leads to **remedial** teaching | Error analysis test |
| Summative | End of unit/course | Grade, certify ("of learning") | Semester-end exam |

- Formative/summative: **Michael Scriven (1967)**.
- **CCE**: continuous (regular, through the year) plus comprehensive (scholastic and co-scholastic). Provided for in RTE Act 2009, Section 29(2)(h).
- Choice Based Credit System grading: 10-point scale (O = 10, A+ = 9, A = 8, B+ = 7, B = 6, C = 5, P = 4, F = 0).

### Norm- vs criterion-referenced
| NRT | CRT |
|---|---|
| Compares a learner with the group | Compares a learner with a fixed standard |
| Percentile, rank, merit list | Mastery or non-mastery, cut-off |
| Example: competitive entrance ranking | Example: driving test, 80% mastery |
| Spreads scores | Checks attainment (Glaser) |

### Qualities of a good test
| Quality | Meaning | Types / methods |
|---|---|---|
| Reliability | Consistency | Test–retest, parallel forms, split-half (Spearman–Brown), KR-20, Cronbach's α |
| Validity | Measures what it is meant to measure | Content, construct, criterion (concurrent, predictive), face |
| Objectivity | Free from scorer's bias | Scoring key |
| Usability | Practical: time, cost, ease | — |

**Item analysis:** p = (RU + RL) / (NU + NL); D = (RU − RL) / n, where n is the size of one group.

### Factors affecting teaching
| Teacher | Learner | Environment | Institution |
|---|---|---|---|
| Subject mastery, communication, personality, attitude, expectations | Motivation, readiness, IQ, prior knowledge, health, socio-economic background | Class size, seating, light, noise, ventilation, peer climate | Infrastructure, library/ICT, administration, policies, workload, academic culture |

### Teaching aids
- Audio (radio, podcast), visual (chart, model, OHP, slide), audio-visual (film, video, smart class).
- Projected (PPT, OHP) vs non-projected (chalkboard, chart, model).
- **Edgar Dale's Cone of Experience (1946)**: direct purposeful experiences at the base, verbal symbols at the apex.

## 2. Memory hooks
1. **Soup analogy (Robert Stake's line).** "When the cook tastes the soup, that's formative; when the guests taste the soup, that's summative."
2. **Reliable but not valid is a faulty bathroom scale** that always shows +2 kg: consistent, wrong. A valid scale must also be consistent, so validity needs reliability.
3. **Doctor analogy for the four types**: Placement is the OPD registration desk, Formative the daily check-up, Diagnostic the blood test, Summative the discharge certificate.
4. **NRT is a race and CRT is a driving test.** In a race you only need to beat others. In a driving test you must clear the standard even if everyone else fails.
5. **Halo is a "sunlight" error**: one bright trait (neat handwriting, good dress) lights up the whole script. **Pygmalion is the "sculptor"**: the teacher's expectation sculpts the student.
6. **Hawthorne is "watched workers work harder"**, from the Western Electric Hawthorne plant studies.
7. **Item analysis "P is for Pass-rate, D is for Difference."** p is the share who got it right. D is the upper minus lower, divided by one group's size.
8. **Dale's cone is a staircase from "doing" to "reading".** Bottom: do it (internship). Middle: see it (demonstration, film). Top: hear or read words.
9. **Factors "T-L-E-I", like "TeLE-I"**: Teacher, Learner, Environment, Institution. If it lives in the room it is Environment. If it lives in the office it is Institution.

## 3. Don't mix up
| This | Not this |
|---|---|
| Formative = during, for improvement | Summative = end, for certification |
| Diagnostic = why the difficulty | Remedial = the cure after diagnosis |
| Reliability = consistency | Validity = accuracy/truthfulness |
| Content validity (expert check of syllabus coverage) | Split-half (reliability) |
| Predictive validity (future performance) | Concurrent validity (present criterion) |
| Halo effect (examiner bias) | Pygmalion effect (teacher expectation) |
| Hawthorne effect (being observed) | Placebo effect (belief in treatment) |
| NRT — rank against the group | CRT — mastery against a standard (term: Glaser, 1963) |

## 4. Exam traps
- "A valid test may be unreliable" is **false**. "A reliable test may be invalid" is **true**.
- Timely feedback comes from **formative** evaluation, never summative.
- The "learning pyramid" percentages (10% read, 90% teach) are **not** Dale's. Avoid any option that credits them to him.
- In item analysis, divide D by **one group's** size, not by the total.
- Scenario answers: prefer **rubrics, anonymous scripts, continuous feedback, remedial teaching**. Reject "fail the student", "ignore", "compare publicly".
