## Solutions
**Q1 — (B).** URL = **Uniform** Resource Locator — the address of a resource on the web. *Also remember:* URI = Uniform Resource Identifier (the broader term); URN = Uniform Resource Name.

**Q2 — (A).** 25 = 16 + 8 + 1 = 1×2⁴ + 1×2³ + 0×2² + 0×2¹ + 1×2⁰ = 11001. *Also remember:* Decimal 10 = 1010, 15 = 1111, 16 = 10000.

**Q3 — (C).** NAAC – National Assessment and Accreditation Council (Bengaluru); NIRF – National Institutional Ranking Framework (MoE, 2015); INFLIBNET – Information and Library Network (Gandhinagar); NMEICT – National Mission on Education through ICT. *Also remember:* NAAC is an autonomous body of UGC; NBA (National Board of Accreditation) accredits technical programmes.

**Q4 — (D).** MPEG = Moving Picture **Experts** Group. *Also remember:* PNG = Portable Network Graphics; MP3 = MPEG-1 Audio Layer 3.

**Q5 — (C).** In binary convention 1 KB = 2¹⁰ = **1024** bytes, so statement 2 is wrong. *Also remember:* 1 byte = 8 bits; each higher unit (KB, MB, GB, TB, PB, EB, ZB, YB) is 1024 times the previous one.

**Q6 — (A).** The base of a number system is the number of distinct symbols it uses; hexadecimal uses 16 (0–9, A=10 … F=15), so R explains A. *Also remember:* Binary base 2 (0,1), octal base 8 (0–7), decimal base 10.

**Q7 — (D).** 255 = 15×16 + 15 = FF₁₆. *Also remember:* 255 = 11111111₂ (the largest value in one byte) = 377₈.

**Q8 — (B).** .xlsx – spreadsheet (Excel), .pptx – presentation (PowerPoint), .mp3 – audio, .exe – executable. *Also remember:* .docx = Word document, .mp4 = video, .zip = compressed archive, .html = web page.

**Q9 — (C).** 1010₂ = 8 + 0 + 2 + 0 = 10, so A is true; but binary place values are powers of **2**, not 10. *Also remember:* The rightmost bit is the LSB (least significant bit); the leftmost is the MSB.

**Q10 — (D).** CAPTCHA = Completely Automated Public Turing test to tell Computers and Humans Apart. *Also remember:* It is named after the Turing Test proposed by Alan Turing (1950).

**Q11 — (A).** GB < TB < PB < EB. *Also remember:* After EB come ZB (zettabyte) and YB (yottabyte); mnemonic in the memory sheet.

**Q12 — (B).** SWAYAM = Study Webs of Active-Learning for Young Aspiring Minds. *Also remember:* MOOC = Massive Open Online Course; NPTEL = National Programme on Technology Enhanced Learning.
