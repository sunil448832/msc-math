## Solutions
**Q1 — (C).** Tim Berners-Lee proposed the WWW at CERN in 1989 (HTML, HTTP, URL, first browser and server). *Also remember:* Vint Cerf and Bob Kahn designed TCP/IP and are called the "fathers of the Internet".

**Q2 — (B).** BCC = Blind Carbon Copy; BCC addresses are not visible to other recipients. *Also remember:* CC = Carbon Copy (visible to all); a "Reply All" does not reach BCC recipients.

**Q3 — (A).** ARPANET (1969) → first e-mail with @ (1971) → WWW proposal (1989) → VSNL public internet in India (15 August 1995). *Also remember:* ARPANET switched to TCP/IP on 1 January 1983 — often called the "birthday of the Internet".

**Q4 — (D).** HTTP 80, HTTPS 443, SMTP 25, DNS 53. *Also remember:* FTP 20/21, POP3 110, IMAP 143, SSH 22, Telnet 23.

**Q5 — (B).** DNS converts **domain names into IP addresses**; IP → MAC mapping is done by ARP. *Also remember:* A MAC address is 48 bits; IPv6 is written in hexadecimal separated by colons.

**Q6 — (A).** Encryption by SSL/TLS is precisely what makes HTTPS secure, so R explains A. *Also remember:* The padlock icon in the address bar indicates an HTTPS connection with a valid certificate.

**Q7 — (C).** Linux is an operating system (kernel by Linus Torvalds, 1991), not a browser. *Also remember:* DuckDuckGo is known for not tracking users; Thunderbird is a desktop e-mail client from Mozilla.

**Q8 — (C).** Smishing = SMS + phishing. Vishing = voice-call phishing; Pharming = redirecting users to a fake website (e.g., via DNS poisoning); Spoofing = faking the sender's identity. *Also remember:* Phishing via e-mail is the parent term.

**Q9 — (B).** Wi-Fi 802.11, Ethernet 802.3, Bluetooth 802.15 (802.15.1), WiMAX 802.16. *Also remember:* Bluetooth is named after the Danish king Harald "Bluetooth".

**Q10 — (A).** In PaaS the provider manages the hardware and OS; the customer only builds/deploys applications. *Also remember:* Order of user control: IaaS (most) > PaaS > SaaS (least).

**Q11 — (D).** Banks never ask for OTPs by e-mail; this is phishing. Do not click, verify through official channels, report. *Also remember:* Report cyber financial fraud quickly on 1930 so the money trail can be frozen.

**Q12 — (D).** A router connects different networks and routes packets by IP address (network layer). A switch forwards within a LAN using MAC addresses; a hub broadcasts to all ports; a repeater only regenerates the signal. *Also remember:* A modem converts digital signals to analog and back (MOdulator–DEModulator).
