**Methods:** Decimal → binary: keep dividing by 2, read remainders bottom-up. Binary → decimal: add place values 1, 2, 4, 8, 16, 32 … under each 1. Binary → octal: group 3 bits; binary → hex: group 4 bits (from the right).

## 2. Memory hooks
1. **Binary place values = doubling rupee notes: 1-2-4-8-16-32-64-128.** To make 25, pick notes 16 + 8 + 1 → put 1 under those, 0 elsewhere → 11001.
2. **Memory ladder mnemonic "Kind Monkeys Give Tasty Peanuts Every Zoo Year"** = KB, MB, GB, TB, PB, EB, ZB, YB.
3. **"Nibble = a small bite of a byte"** — 4 bits is half a byte, as a nibble is half a bite.
4. **"1024, not 1000"** — computers count in powers of 2; 2¹⁰ = 1024 is the "computer's thousand".
5. **Hex letters: "A is for 10 fingers"** — A = 10, then count on: B11, C12, D13, E14, F15. FF = 255, the biggest one-byte value.
6. **Number-system bases = a ladder 2-8-10-16:** binary (two-sided coin), octal (octopus has 8 arms), decimal (10 fingers), hexadecimal (hex = 6, plus deci = 10 → 16).
7. **"Experts" for both JPEG and MPEG** — both are named after *groups of experts*: JPEG = Joint Photographic **Experts** Group, MPEG = Moving Picture **Experts** Group. Any "Exchange" is a trap.
8. **"Uniform" URL** — think of a school uniform: every address follows one standard format. "Universal" is the trap.
9. **"-AM" family:** RAM (Random), SRAM (Static), DRAM (Dynamic) — all volatile. The **R-O-M** family (ROM, PROM, EPROM, EEPROM) keeps data — "ROM = Remains On Memory".
10. **OMR vs OCR vs MICR in one exam hall:** you fill OMR bubbles (Marks), the question paper text is scanned by OCR (Characters), and your fee cheque is read by MICR (Magnetic ink).
11. **SWAYAM = "Swayam" (self)** — self-paced learning; letters spell **S**tudy **W**ebs of **A**ctive-learning for **Y**oung **A**spiring **M**inds.
12. **TCP/IP as India Post:** IP writes the address; TCP is registered post that confirms delivery; UDP is a regular postcard — faster, no receipt.

## 3. Don't mix up
| Pair | Difference |
|---|---|
| URL vs URI | Locator (address) vs the broader Identifier |
| HTML vs HTTP | Language to build pages vs protocol to transfer them |
| NIC vs NIC | Network Interface Card vs National Informatics Centre — read the context |
| NAAC vs NBA | Institutions (general) vs technical programmes |
| NAAC vs NIRF | Accreditation grade vs annual ranking |
| OCR vs OMR | Characters vs marks/bubbles |
| Bit vs Byte | 1 binary digit vs 8 bits |
| KB (binary) vs kB (decimal SI) | 1024 bytes vs 1000 bytes |
| .exe vs .apk | Windows vs Android installer |
| GIF vs JPEG | Supports simple animation, 256 colours vs photographs, lossy compression |
| Octal vs Hex grouping | 3 bits vs 4 bits |

## 4. Exam traps
- URL = **Uniform** (not Universal) Resource Locator.
- MPEG/JPEG = **Experts** Group (not Exchange/Expert's).
- 1 KB = **1024** bytes (binary convention); 1 nibble = **4** bits.
- Binary place values are powers of **2**, not 10.
- Hex "10" means decimal **16**, not ten.
- CAPTCHA contains "**Turing** test", not "Tracking".
- ASCII is **7-bit** (128 characters); extended ASCII uses 8 bits.
- Wi-Fi is a trademark; "Wireless Fidelity" is the popular expansion — accept it if offered, but don't argue over it.
