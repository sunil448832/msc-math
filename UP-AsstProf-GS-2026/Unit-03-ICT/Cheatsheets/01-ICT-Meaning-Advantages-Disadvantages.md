## 1. Core facts

### Meaning of ICT
**ICT = Information and Communication Technology** = IT (computers, software, data) **+** communication technology (internet, telephone, radio, TV, satellites). It covers all tools used to **create, store, process, transmit and share** information.

| Component | Examples |
|---|---|
| Hardware | CPU, monitor, keyboard, printer, router |
| Software | OS (Windows, Linux, Android), applications (Word, browser) |
| Networks | LAN, Internet, mobile networks, satellite |
| Data/content | Text, audio, video, e-books, databases |
| People & processes | Users, teachers, digital literacy |

### Computer basics
| Item | Fact |
|---|---|
| Father of computer | Charles Babbage (Analytical Engine) |
| First programmer | Ada Lovelace |
| ENIAC | 1946, early general-purpose electronic computer (vacuum tubes) |
| India's supercomputer | PARAM 8000 (1991), C-DAC Pune, Vijay Bhatkar |
| CPU parts | ALU (calculations), CU (control), Registers (fastest memory) |
| Stored-program concept | John von Neumann |

| Generation | Technology |
|---|---|
| 1st | Vacuum tubes |
| 2nd | Transistors |
| 3rd | Integrated Circuits (IC) |
| 4th | Microprocessor (VLSI) |
| 5th | Artificial Intelligence (ULSI, parallel processing) |

### Memory
| Type | Volatile? | Note |
|---|---|---|
| Registers | Yes | Inside CPU, fastest |
| Cache (SRAM) | Yes | Between CPU and RAM |
| RAM (DRAM) | Yes | Main/primary working memory |
| ROM (PROM, EPROM, EEPROM) | No | Stores BIOS/firmware |
| Secondary (HDD, SSD, pen drive, CD/DVD) | No | Long-term storage |

Speed: **Registers > Cache > RAM > SSD > HDD**. Cost per byte follows the same order; capacity is the reverse.

Units: 4 bits = 1 nibble; 8 bits = 1 byte; 1 KB = 1024 B; KB → MB → GB → TB → PB → EB → ZB → YB (each ×1024).

### Advantages vs disadvantages
| Advantages | Disadvantages |
|---|---|
| Anytime-anywhere learning, MOOCs | Digital divide (rural/urban, rich/poor, gender) |
| Speed, storage, accuracy | Cyber crime, phishing, data theft |
| Cheap global communication | Health issues: eye strain, RSI, addiction |
| E-governance, transparency | Loss of privacy; misinformation |
| Personalised and multimedia learning | Plagiarism, reduced face-to-face interaction |
| Research access (Shodhganga, e-journals) | E-waste; dependence on power/connectivity |

## 2. Memory hooks
1. **Kitchen analogy for memory.** Registers = the spoon in your hand; Cache = the plate on the table; RAM = the kitchen counter (wiped clean when you leave — volatile); Hard disk = the storeroom (stays even when the lights go off).
2. **ROM = "Read-Only Memory" = a printed textbook.** You can read it, the text stays even if the light is off, and BIOS is its "first chapter" read at boot.
3. **Generations mnemonic "V-T-I-M-A"** — "**V**ery **T**all **I**ndians **M**ake **A**rt": Vacuum tube, Transistor, IC, Microprocessor, AI.
4. **"Babbage = Baap (father)."** Both start with B-a-b; his partner Ada = "Aadi (first) programmer".
5. **SWAYAM date trick 9-7-17:** "9 July 2017 — 9, 7, 17 all odd". SWAYAM credit cap: "**20 → 40** — doubled in 2021, like the 2020s".
6. **INFLIBNET's "Shodh" family as a river:** Shodh**gangotri** = the source (synopsis, where research begins), Shodh**ganga** = the full river (finished thesis), e-Shodh**Sindhu** = the ocean of journals.
7. **Who runs what — "Kharagpur keeps the Library, NCERT keeps DIKSHA (teachers' Diksha = initiation)".** NDLI → IIT Kharagpur; DIKSHA → NCERT, launched on Teachers' Day (5 Sept 2017).
8. **NPTEL = "IITs teaching on TV/Net"** — from 2003; UP link: IIT Kanpur is one of the founding institutions.
9. **Digital divide = two lanes of a highway:** one lane has a car (device), fuel (data) and a licence (skills); the other has none. Remove any one and you are still left behind.
10. **Section 66A struck = "6-6-A gone in 2015."** The Shreya Singhal case protected free speech online.

## 3. Don't mix up
| Pair | Difference |
|---|---|
| RAM vs ROM | RAM volatile, read-write; ROM non-volatile, mostly read |
| SRAM vs DRAM | SRAM: faster, cache, no refresh; DRAM: main memory, needs refresh |
| Shodhganga vs Shodhgangotri | Full theses vs synopses |
| SWAYAM vs SWAYAM Prabha | Online MOOCs portal vs DTH TV channels |
| DIKSHA vs NDLI | NCERT school/teacher platform vs IIT Kharagpur digital library |
| e-PG Pathshala vs e-ShodhSindhu | PG e-content vs e-journal access consortium |
| IT vs ICT | ICT adds the *communication* part (networks, telecom, broadcast) |
| Compiler vs Interpreter | Whole program at once vs line by line |

## 4. Exam traps
- "Cache is part of the hard disk" — **wrong**; cache sits with/inside the CPU.
- BIOS is **firmware/system software**, not application software.
- SWAYAM is **not** only for engineering — it runs from school level to PG, all subjects.
- The 40% SWAYAM limit is from the **2021** regulations (2016 allowed 20%).
- Touchscreen is **both** input and output; plotter is **output**.
- Shodhganga is run by **INFLIBNET (Gandhinagar)**, not by UGC directly and not by IIT Kharagpur.
- Sec 66A was **struck down**, not merely amended.
