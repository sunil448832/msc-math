# UP Assistant Professor (Higher Education) — Mathematics 2026
**Exam:** UPESSC (formerly UPHESC), Prayagraj · **Subject code:** 75 · **Format:** 100 MCQs (30 GK + 70 Mathematics) · 2 hours · 200 marks. This pattern comes from the previous paper; see [Mock Tests & Blueprint](../UP-AsstProf-Mock-Tests-2026/00-Paper-Blueprint.md).

**Related:** [GK question bank](../UP-AsstProf-GS-2026/README.md) · [Full-length mock tests](../UP-AsstProf-Mock-Tests-2026/)

These question banks and revision sheets follow the official syllabus, arranged module by module. Each topic has two files:
- `Questions/` has 10–14 hand-picked MCQs in the past-paper style. Every question type is covered once, so there is no repetition. The answer key and solutions are at the end of the file.
- `Cheatsheets/` has a formula and concept sheet for the same topic.

See [STYLE-GUIDE.md](STYLE-GUIDE.md) for the question-type tags (`[Concept]`, `[Numerical]`, `[Multi-Statement]`, `[Assertion-Reason]`, `[Match]`, `[NOT-true / Counterexample]`, `[Application]`) and the difficulty stars (★ / ★★ / ★★★).

**Viewing:** open any `.md` file in VS Code and press `Ctrl+Shift+V` to render the math.

## Suggested way to use
1. Read the topic's cheatsheet (about 10 minutes).
2. Attempt the question file under timed conditions (about 1.5 minutes per question) without looking at the key.
3. Check your answers against the solutions. Any question you missed shows which cheatsheet line to re-read.
4. In the last week, revise only the cheatsheets and their **Exam traps** sections.

> The questions follow the style and themes of past UPHESC/UPESSC, CSIR-NET and GATE papers. They are original practice questions, not reproductions of any specific paper. Check the official UPESSC notification for any change to the pattern, such as negative marking.
