# Blueprint of the actual UPHESC/UPESSC Mathematics paper (subject code 75)
*Analysed from `uphesc-assistant-professor-question-paper-mathemat.pdf` (the paper refers to the Union Budget 2025–26, so it is from the 2025 cycle).*

## Pattern
| Item | Detail |
|---|---|
| Duration | **2 hours (120 min)**. No candidate may leave before 120 minutes. |
| Total marks | **200** |
| Questions | **100**: Part I has **30 General Knowledge**, Part II has **70 Mathematics** |
| Marks per question | 2 (200 ÷ 100) |
| Format | 4-option MCQ on an OMR sheet. The paper is bilingual, and the **English version prevails** if the two differ. |
| Time budget | GK about 20 min (40 s per question), Maths about 95 min (80 s per question), 5 min to check the OMR |

## Question formats seen (Mathematics)
| Format | Count (approx.) | Note |
|---|---|---|
| Direct one-liner (value, count, formula) | ~50 | Mostly **standard textbook results**, answerable in under 1 minute |
| Assertion–Reason | ~5 | Standard 4 options, worded "Both (A) and (R) are correct…" |
| Arrange in a sequence | ~3 | For example an inclusion hierarchy (topological ⊃ normed ⊃ Banach ⊃ Hilbert) or logical steps |
| Match List-I/List-II | ~4 | Codes such as "a – III, b – IV, c – II, d – I" |
| "Which is NOT true / incorrect" | ~4 | |
| Multi-select ("a, c only") | ~2 | |

**Takeaway:** the paper rewards breadth and quick recall of classic results far more than deep proofs. Every unit is worth about 6–9 questions, so **no unit can be skipped**. Standard results such as the Gaussian curvature of a sphere, the torsion of a helix, σ(n), Fermat-type remainders and Newton–Raphson's convergence order come back again and again.
