# Full-Length Mock Tests — UPESSC Assistant Professor Mathematics 2026

These five papers follow the pattern of the actual UPHESC/UPESSC paper exactly: **100 questions in 2 hours, worth 200 marks**. Part I has 30 GK questions and Part II has 70 Mathematics questions. Each paper uses the same unit-wise distribution and question formats as the real paper, including Assertion–Reason, "Arrange in a sequence", List matching, "NOT true" and multi-select questions. See the [Paper Blueprint](00-Paper-Blueprint.md) for the analysis behind this.

## How to take a mock
1. Sit without interruptions, set a timer for **120 minutes** and answer on a sheet of paper. Aim for about 20 minutes on Part I and 95 minutes on Part II.
2. Score +2 per correct answer using the answer grid at the top of the solutions file.
3. Note which **unit** each wrong answer came from. Then revise that unit's cheatsheet and question bank:
   - [Maths topic bank](../UP-AsstProf-Maths-2026/README.md)
   - [GK topic bank](../UP-AsstProf-GS-2026/README.md)
4. Space the mocks out, and take them in order. Mocks 04 and 05 are deliberately harder than the last UP paper, so a low score on them does not predict a low exam score. See the [difficulty review](00-Difficulty-Review-HPSC-2025.md).

> The questions are original and modelled on the previous paper's style. Current-affairs facts were checked by web search up to October 2026. Each GK solutions section lists the sources it used.
